# 佘培琳个人简历

## 项目简介

这是一个基于React的个人简历网站，展示佘培琳的个人信息、技能、工作经验和项目经历。

## 项目结构

```
resume-react/
├── public/                 # 静态资源文件
│   ├── spl.jpg            # 头像图片
│   └── background.png     # 背景图片
├── assets/                # 构建后的资源文件
│   ├── index-BRZB8Y48.js # 主JavaScript文件
│   └── index-Da2dlR2W.css # 主CSS样式文件
├── dist/                  # 构建输出目录
│   ├── index.html         # 主HTML文件
│   └── assets/            # 构建后的资源文件
├── index.html             # 主HTML文件
└── README.md              # 项目说明文档
```

## 技术栈

- **前端框架**: React 19.1.1
- **构建工具**: Vite
- **样式**: CSS3
- **图标**: Font Awesome 4.7.0
- **部署**: GitHub Pages

## 本地开发

由于这是构建后的项目，如需本地开发：

1. 克隆仓库
2. 安装依赖: `npm install`
3. 启动开发服务器: `npm run dev`
4. 构建项目: `npm run build`
